Difficulty: Basic

Symptoms

The cooling fan model in the server room scene is completely static. It has received the run command via the global event system, but no rotation is occurring in the update loop.

Expected Behavior

Upon initialization, the fan should smoothly rotate continuously around its Z-axis at the defined rotationSpeed.

Actual Behavior

The mesh remains static. No errors are thrown in the main console, indicating a logical or syntax issue within the update method rather than a missing reference.

Hint

Check how the rotation vector is being constructed. Is it applying the speed to the correct axis?
