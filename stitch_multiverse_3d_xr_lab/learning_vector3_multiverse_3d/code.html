Working with Vector3

In Multiverse 3D, positions, scales, and rotations are often represented using Vector3 structs.

A Vector3 represents a point or vector in 3D space, containing X, Y, and Z components.

Example

// Create a new position
Vector3 newPos = new Vector3(0f, 5f, 0f);

// Apply to object
gameObject.transform.position = newPos;
