Challenge: Orbit Mechanism

Implement an orbital mechanic for a satellite object around a central planet object in 3D space.

Requirements:

  • The satellite must continuously rotate around the planet's Y-axis.
  • The orbital radius should be maintained exactly at 50 units.
  • The satellite must face the direction of its orbit (tangential velocity vector).
  • The orbital speed should be adjustable via a public variable orbitalSpeed.

Constraints:

  • Do NOT use built-in physics engine joints or constraints.
  • Calculate the position using trigonometric functions (Sin/Cos) or Quaternions.
  • Assume the planet is at the origin (0, 0, 0).

Expected Behavior:

  • Upon execution, the satellite immediately snaps to the 50-unit radius if not already there.
  • Smooth, framerate-independent motion using deltaTime.
